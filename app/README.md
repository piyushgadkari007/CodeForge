## Overview
PhantomGuard is an AI-driven cyber defense and surveillance system designed to detect, analyze, and respond to spyware-like attacks in real time. The system integrates a drone-based (mobile camera) scanning interface with a central monitoring dashboard, transforming passive monitoring into an active, intelligent defense mechanism.
Unlike traditional security systems that react after damage occurs, PhantomGuard provides instant detection, deception-based response, and visual tracking, making cybersecurity proactive and interactive.

## The Problem
Modern cyber threats such as spyware and unauthorized access are:
⚠️ Difficult to detect in real time
⚠️ Often invisible to users
⚠️ Reactive systems respond too late
⚠️ Lack of visualization makes analysis difficult
Additionally, there is a gap between physical monitoring systems (like drones/cameras) and cybersecurity intelligence, limiting real-world applications.

## Core Solution
PhantomGuard introduces a real-time cyber defense system that:
    -Detects spyware-like attacks within seconds
    -Automatically activates a defense protocol
    -Deploys fake data (deception layer) to mislead attackers
    -Tracks attacker activity via a live visualization dashboard
    -Uses a mobile phone camera as a drone prototype for scanning environments
This creates a unified system combining monitoring + detection + response + visualization.

## System Architecture & Workflow
1. Backend Processing (Flask Server)
    -Detects anomaly within 5 seconds
    -Changes system state dynamically
    -Generates simulated attacker location and signal data
2. Defense Mechanism
    -Deploys fake data to attacker
    -Activates PhantomGuard UI on drone 
    -Initiates protection visualization (shield + scan)
3. Monitoring Dashboard 
    Displays:
        -Attack detection
        -Signal strength
        -AI threat analysis
        -System logs
